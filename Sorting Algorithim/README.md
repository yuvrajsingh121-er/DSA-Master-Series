# 🔄 Sorting Algorithms in Java

Welcome to the **Sorting Algorithm** directory of the `DSA-Master-Series`! This folder contains clean, well-commented implementations of fundamental sorting techniques written in Java. 

---

## 📂 Included Implementations

| File Name | Description | Time Complexity (Avg/Worst) | Space Complexity |
| :--- | :--- | :--- | :--- |
| **`BuiltInCollectionSort.java`** | Sorting using Java Collections (`Collections.sort()`) | $O(n \log n)$ | $O(n)$ |
| **`BuiltInSort.java`** | Sorting primitive arrays using `Arrays.sort()` (Dual-Pivot Quicksort) | $O(n \log n)$ | $O(\log n)$ |
| **`CountingSort.java`** | Non-comparison integer sorting algorithm | $O(n + k)$ | $O(n + k)$ |
| **`CustomSort.java`** | Custom sorting logic using comparators/lambdas | Varies | Varies |
| **`InsertionSort.java`** | Efficient for small data sets or nearly sorted arrays | $O(n^2)$ | $O(1)$ |
| **`SelectionSort.java`** | Simple comparison-based in-place sorting | $O(n^2)$ | $O(1)$ |
| **`bubblesorting.java`** | Repeatedly swapping adjacent elements if in wrong order | $O(n^2)$ | $O(1)$ |
